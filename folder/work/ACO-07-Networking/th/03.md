- ตรวจสอบกฎของ network ACL
- ตรวจสอบกฎของ route table
หากคุณเข้าถึงทรัพยากรในเครือข่ายที่ peer กันไม่ได้:
- ตรวจสอบให้แน่ใจว่าคำขอ peering ได้รับการอนุมัติแล้ว
- ตรวจสอบกฎของ security group: ต้องใช้ช่วง CIDR block ของ VPC A เพื่ออนุญาตการเข้าถึงจาก VPC B หรือใช้ security group ID ของ VPC A
- ตรวจสอบ network ACLs: คุณกำลังห้ามทราฟฟิกภายนอกทั้งหมดอยู่หรือไม่?
