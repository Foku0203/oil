Amazon CloudWatch Events ส่งสตรีมของเหตุการณ์ระบบที่อธิบายการเปลี่ยนแปลงของทรัพยากร AWS แบบเกือบเรียลไทม์ กฎง่าย ๆ สามารถจับคู่เหตุการณ์และส่งไปยังฟังก์ชันหรือสตรีมเป้าหมายหนึ่งตัวหรือมากกว่า CloudWatch Events รับรู้การเปลี่ยนแปลงด้านการปฏิบัติงานทันทีที่เกิดขึ้น
CloudWatch Events ตอบสนองต่อการเปลี่ยนแปลงเหล่านี้และดำเนินการแก้ไขตามความจำเป็น ด้วยการส่งข้อความตอบสนองต่อสภาพแวดล้อม เรียกใช้ฟังก์ชัน ทำการเปลี่ยนแปลง และเก็บข้อมูลสถานะ คุณยังใช้ CloudWatch Events ตั้งเวลาการกระทำอัตโนมัติที่ทริกเกอร์ตัวเองตามเวลาที่กำหนด โดยใช้ cron หรือ rate expressions ได้

> หมายเหตุ: AWS Config มีคลังการตรวจสอบการปฏิบัติตามข้อกำหนดที่กำหนดไว้ล่วงหน้าจำนวนมาก และคุณสร้างการตรวจสอบเพิ่มเติมได้ด้วยการเขียน AWS Config Rule ของคุณเองโดยใช้ AWS Lambda
