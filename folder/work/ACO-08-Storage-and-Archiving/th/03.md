=== P061
# File gateway
แผนภาพ: ศูนย์ข้อมูลองค์กรที่สถานที่ของลูกค้า (Customer premises – Corporate data center): Server → NFS และ/หรือ SMB → File gateway → HTTPS → AWS Cloud: Amazon Simple Storage Service (S3) → เก็บถาวร (Archive) → Amazon S3 Glacier

=== P062
# Volume gateway
แผนภาพ: ศูนย์ข้อมูลองค์กรที่สถานที่ของลูกค้า: Server → iSCSI → Volume gateway → HTTPS → AWS Cloud: Amazon Simple Storage Service (S3) → สำรองข้อมูล (Backup) เป็น Amazon Elastic Block Store (EBS) snapshots

=== P063
# Tape gateway
แผนภาพ: ศูนย์ข้อมูลองค์กรที่สถานที่ของลูกค้า: Server (ซอฟต์แวร์สำรองข้อมูล – Backup) → iSCSI → Tape gateway → HTTPS → AWS Cloud:
- เทปเสมือน (Virtual tapes) จัดเก็บใน Amazon S3
- เก็บถาวร (Archive) → เทปที่เก็บถาวร (Archived tapes) จัดเก็บใน Amazon S3 Glacier (Vault)

=== P064
# ประเด็นสำคัญ (Key Takeaways)
- AWS Storage Gateway ติดตั้งอยู่ on-premises และเชื่อมสภาพแวดล้อมเข้ากับ AWS Cloud
- ใช้ AWS Storage Gateway สำหรับสถานการณ์แบบไฮบริดที่ต้องมีพื้นที่จัดเก็บบางส่วน on-premises โดยถ่ายข้อมูลไปยัง Amazon S3, Amazon S3 Glacier หรือ Amazon EBS
- AWS Storage Gateway มีสามตัวเลือก ได้แก่ file, volume และ tape

=== P066
# AWS Transfer for SFTP
- SFTP server แบบมีผู้ดูแลให้และพร้อมใช้งานสูง ใช้ส่งข้อมูลเข้าและออกจาก Amazon S3
คุณสมบัติ:
- ถ่ายโอนอย่างปลอดภัยด้วย SFTP เข้าและออกจาก AWS
- คงเวิร์กโฟลว์เดิมไว้ได้
- ใช้งานง่าย
- ข้อมูลจัดเก็บใน Amazon S3 bucket

=== P067
# AWS DataSync
- บริการแบบมีผู้ดูแลให้ (Managed service)
- AWS DataSync Agent (โปรโตคอล NFS)
- ซิงก์ข้อมูลระหว่าง on-premises กับ AWS
- เชื่อมต่อผ่านอินเทอร์เน็ตหรือ AWS Direct Connect
- มีประสิทธิภาพและรวดเร็ว

=== P068
# การใช้ AWS DataSync
แผนภาพ: ศูนย์ข้อมูลองค์กร: ระบบไฟล์ที่ใช้ร่วมกัน (Shared file system) → NFS → AWS DataSync Agent → TLS → AWS Cloud: AWS DataSync → Amazon S3 Bucket และ Amazon Elastic File System

=== P069
# AWS Snowball
คุณสมบัติ:
- กล่องบรรจุที่ปลอดภัย (Secure enclosure)
- ขนาด 50/80TB ส่งพร้อมกันหลายเครื่องได้ (Shipped in parallel)
- โลจิสติกส์ที่เรียบง่าย (Simplified logistics)
- เข้ารหัสแข็งแกร่งตั้งแต่ต้นจนจบ (Strong encryption, end-to-end)
กระบวนการ: ชุดข้อมูลขนาดใหญ่ของลูกค้า (Large customer dataset) → โหลดลงอุปกรณ์ Snowball → ขนส่งพร้อมการควบคุมดูแลตลอดเส้นทาง (End-to-end Custody – escorted) → ชุดข้อมูลของลูกค้าถูกโหลดเข้า AWS (Customer dataset loaded)
