สิ่งที่อยู่ใน EC2 instance (EC2 instance contents): AWS Command Line Interface (AWS CLI)
- 1. ติดตั้งและตั้งค่า AWS CLI บนเครื่องด้วยตนเอง
- 2. ทำงานกับบริการ AWS โดยใช้ AWS CLI
--- notes
