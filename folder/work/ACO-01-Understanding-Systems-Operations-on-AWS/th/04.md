# ผลลัพธ์ของ AWS CLI (ในรูปแบบ JSON)
```
$ aws ec2 describe-instances
{
"Reservations": [
{
"Groups":[],
"Instances":[
{
"ImageId":"ami-423bec20",
"InstanceId": "i-068035fce1e9abcc9",
"InstanceType": "m5.large",
"KeyName": "mykeypair",
"LaunchTime": "2019-06-15T 11:55:16.000Z",
"Placement": {
"AvailabilityZone": "us-west-2a"
}
"State":{
"Code": 16,
"Name": "running"},
"PublicIPAddress": "54.252.186.255",
"PublicDnsName": "ec2-54-252-186-255.us-west-2.compute.amazonaws.com",
"PrivateIPAddress": "10.0.50.14",
```
คำอธิบายประกอบในสไลด์:
- `describe-instances` – ขอรายละเอียดของ Amazon EC2 instances ทั้งหมดที่มีอยู่ในบัญชี
- `"Instances":[` – รายการหลายรายการถูกส่งกลับมาเป็นอาร์เรย์ของค่า (arrays of values)
- `"AvailabilityZone":` – คู่ชื่อ-ค่า (name-value pairs) ที่คั่นด้วยเครื่องหมายโคลอน
--- notes
บนสไลด์ บรรทัดแรกแสดงคำสั่ง AWS CLI ที่เพิ่งรันไป (`aws ec2 describe-instances`) ส่วนบรรทัดที่เหลือด้านล่างแสดงผลลัพธ์ของคำสั่ง AWS CLI นั้น
ผลลัพธ์ของคำสั่ง `aws ec2 describe-instances` ถูกส่งกลับมาเป็นอาร์เรย์ของ Reservations แต่ละ reservation มีอาร์เรย์ของ Instances หนึ่งตัวหรือมากกว่าผูกอยู่ **หมายเหตุ (NOTE):** ทั้ง reservations และ instances ถูกส่งกลับด้วยไวยากรณ์อาร์เรย์ของ JSON ต่อไปในคอร์สนี้จะกล่าวถึงการใช้สัญกรณ์อาร์เรย์เพื่อกรองผลตอบกลับ
คุณสมบัติที่ผูกกับแต่ละ instance เช่น public DNS name, สถานะของ instance ฯลฯ ถูกส่งกลับเป็นคู่ชื่อ-ค่าแบบง่ายในเครื่องหมายคำพูด คั่นด้วยโคลอน
รายละเอียดเพิ่มเติมเกี่ยวกับคำสั่ง `aws ec2 describe-instances` ดูได้ที่ https://docs.aws.amazon.com/cli/latest/reference/ec2/describe-instances.html

# จำกัดผลลัพธ์: ตัวเลือก --query
ใช้ตัวเลือก `--query` เพื่อจำกัดฟิลด์ที่แสดงในชุดผลลัพธ์ (โครงสร้าง: Service / Operation / Parameters)
แสดงเฉพาะ Amazon EC2 instance ตัวแรกในรายการ:
```
aws ec2 describe-instances –-query 'Reservations[0].Instances[0]'
```
แสดงชื่อสถานะ (named state) ของ instance ตัวแรก:
```
aws ec2 describe-instances --query 'Reservations[0].Instances[0].State.Name'
```
แสดงชื่อสถานะของทุก instance โดยใช้ wildcard (*):
```
aws ec2 describe-instances --query 'Reservations[*].Instances[*].State.Name'
```
--- notes
ตัวเลือก `--query` สามารถใส่เพิ่มในคำสั่งส่วนใหญ่ได้ตามต้องการ เพื่อจำกัดผลลัพธ์ที่ส่งกลับมา การกรองผลลัพธ์ทำที่ฝั่งไคลเอนต์ (client side)
คุณควรเขียน query ตามข้อกำหนด JMESPath ซึ่งกำหนดไวยากรณ์สำหรับค้นหาในเอกสาร JSON ข้อมูลเพิ่มเติมเกี่ยวกับ JMESPath ดูได้ที่ http://jmespath.org/specification.html
query สร้างขึ้นโดยการระบุส่วนย่อยของผลตอบกลับที่คุณต้องการดู คุณระบุส่วนย่อยได้ด้วยการอ้างถึงเส้นทาง (path) แบบเต็มไปยังส่วนนั้น โดยเริ่มจากองค์ประกอบบนสุดของผลตอบกลับ
องค์ประกอบของอาร์เรย์อ้างอิงได้ด้วยดัชนีที่เริ่มจากศูนย์ (zero-based indexing) ตัวอย่างเช่น หากต้องการดูรายละเอียดเฉพาะ instance ตัวแรกที่ได้จากการดำเนินการ describe-instances ของ Amazon EC2 ให้ใช้เส้นทาง `Reservations[0].Instances[0]` ใน query ซึ่งหมายความว่า “สำหรับ reservation แรก ให้ส่งรายละเอียดของ instance ตัวแรกกลับมา” คุณสามารถระบุเพิ่มเติมได้ว่าต้องการดูเฉพาะคุณสมบัติบางอย่างของ instance นี้ เช่น สถานะการทำงานปัจจุบัน
อีกตัวอย่างหนึ่ง หากต้องการดูสถานะของทุก instance คุณสามารถใช้ wildcard แทนดัชนี เพื่อให้ได้ผลลัพธ์จากทุก reservation และทุก instance ไวยากรณ์ `[*]` ใช้ได้กับทุกอาร์เรย์ เพื่อระบุว่าคุณต้องการดูคุณสมบัติหรือองค์ประกอบลูกที่ระบุ สำหรับสมาชิกทุกตัวในอาร์เรย์นั้น

=== S035
# จำกัดผลลัพธ์: ตัวเลือก --filter
ตัวเลือก `--filter` ใช้จำกัดชุดผลลัพธ์โดยกรองที่ฝั่งเซิร์ฟเวอร์ (server side)
แสดงเฉพาะ instances ที่เป็น Windows:
```
aws ec2 describe-instances –-filter "Name=platform,Values=windows"
```
ค้นหา instanceIds ของทุก instance ในบัญชี แต่แสดงเฉพาะ instanceIds ของ instance แบบ t2.micro และ t2.small:
```
aws ec2 describe-instances \
--query "Reservations[*].Instances[*].InstanceId” \
–-filter “Name=instance-type,Values=t2.micro,t2.small”
```
--- notes
ตัวเลือก `--filter` ใช้จำกัดชุดผลลัพธ์โดยกรองที่ฝั่งเซิร์ฟเวอร์
ตัวอย่างแสดงการใช้ `--filter` กับคำสั่ง `aws ec2 describe-instances`
ในตัวอย่างแรก ผลลัพธ์ที่ส่งกลับถูกกรองให้แสดงเฉพาะ instances ที่รัน Windows Server
ตัวอย่างที่สองแสดงคำสั่งที่มีทั้งตัวเลือก `–query` และ `–filter` คำสั่งนี้ค้นหา instanceIds ของทุก instance ในบัญชี แล้วแสดงเฉพาะ instanceIds ของ instance แบบ t2.micro และ t2.small

=== S038
# ตัวเลือกอื่นของ CLI: --dry-run
ตัวเลือก `--dry-run`:
- ตรวจสอบสิทธิ์ที่จำเป็นโดยไม่ส่งคำขอจริง
- ให้ผลตอบกลับเป็นข้อผิดพลาดหากไม่ได้รับอนุญาต
```
aws ec2 run-instances --image-id ami-1a2b3c4d --count 1 --instance-type c5.large --key-name MyKeyPair --security-groups MySecurityGroup --dry-run
```
--- notes
อีกตัวเลือกหนึ่งของ CLI คือ `--dry-run` ใช้เพื่อการทดสอบ เพราะตรวจสอบว่ามีสิทธิ์ที่จำเป็นสำหรับ action นั้นหรือไม่ โดยไม่ส่งคำขอจริง
นอกจากนี้ โดยปกติจะให้ผลตอบกลับเป็นข้อผิดพลาด:
- หากมีสิทธิ์ที่จำเป็น ผลตอบกลับข้อผิดพลาดคือ DryRunOperation
- หากไม่มีสิทธิ์ คำสั่งจะล้มเหลวแม้ไม่ใส่ตัวเลือก `–dry-run` ทำให้ผลตอบกลับข้อผิดพลาดเป็น UnauthorizedOperation

# คำสั่ง CLI ที่ใช้บ่อย
**Amazon EC2**
- `aws ec2 run-instances`
- `aws ec2 describe-instances`
- `aws ec2 create-volume`
- `aws ec2 create-vpc`
**Amazon S3**
- `aws s3 ls`
- `aws s3 cp`
- `aws s3 mv`
- `aws s3 rm`
--- notes
ต่อไปนี้คือรายการสั้น ๆ ของคำสั่ง AWS CLI ที่ใช้บ่อย คำสั่งเหล่านี้เกี่ยวกับบริการ AWS ที่ได้รับความนิยมสูงสุดสองบริการ ได้แก่ Amazon Elastic Compute Cloud (Amazon EC2) และ Amazon Simple Storage Solution (Amazon S3)
**หมายเหตุ (NOTE):** actions ของ Amazon Virtual Private Cloud (VPC) และ Amazon Elastic Block Store (Amazon EBS) ทำผ่านคำสั่ง `aws ec2`
คำอธิบายสั้น ๆ ของแต่ละคำสั่งบนสไลด์และการทำงานของคำสั่ง:
คำสั่งของ Amazon EC2:
- `aws ec2 run-instances`: launch instances ตามจำนวนที่ระบุจาก AMI
- `aws ec2 describe-instances`: แสดงรายละเอียดของ instances ทั้งหมดที่มีอยู่ในบัญชี
- `aws ec2 create-volume`: สร้าง Amazon EBS volume ที่สามารถต่อเข้ากับ instance ใน Availability Zone เดียวกันได้
- `aws ec2 create-vpc`: สร้าง VPC ด้วย Classless Inter-Domain Routing (CIDR) block ที่ระบุ
คำสั่งของ Amazon S3:
- `aws s3 ls`: แสดงรายการ Amazon S3 objects และ common prefixes ภายใต้ prefix หนึ่ง หรือแสดง Amazon S3 buckets ทั้งหมด สามารถระบุ bucket เฉพาะในบัญชีได้ และคำสั่ง ls จะแสดงรายการเนื้อหาใน bucket ที่ระบุ
- `aws s3 cp`: คัดลอกไฟล์ไปยัง จาก หรือระหว่างตำแหน่งใน Amazon S3 ใช้คัดลอกไฟล์ในเครื่องขึ้น Amazon S3, คัดลอกไฟล์จาก Amazon S3 ลงแล็ปท็อป หรือคัดลอกไฟล์ใน Amazon S3 ไปยังตำแหน่งอื่นใน Amazon S3
- `aws s3 mv`: ย้ายไฟล์ในเครื่องหรือ Amazon S3 object ไปยังตำแหน่งอื่นในเครื่องหรือใน Amazon S3
- `aws s3 rm`: ลบ Amazon S3 object
