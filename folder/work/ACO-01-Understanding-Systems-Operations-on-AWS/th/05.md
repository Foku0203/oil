# คำตอบของโมดูล 1 (Module 1 answer)
ผู้รับเหมาของรัฐบาลกลางสหรัฐฯ ที่ตั้งอยู่ในเมือง Seattle กำลังขยายการใช้งานคลาวด์ไปยังประเทศเยอรมนี เยอรมนีมี**กฎเกณฑ์อธิปไตยข้อมูลที่เข้มงวด**ห้าม**ข้อมูล**ที่มีต้นทางในเยอรมนี**ออกนอกภูมิภาค** ผู้รับเหมามีพนักงานหลายพันคน มีบัญชี AWS จำนวนมาก และใช้ directory service ในการจัดการ**การเข้าถึงบัญชี** AWS **ผู้ตรวจสอบจะ**ต้องเข้าถึงทุกระบบที่จัดเก็บและประมวลผลข้อมูลของเยอรมนี เพื่อยืนยันว่าข้อมูลถูกจัดการอย่างถูกต้อง
**ควรให้สิทธิ์การเข้าถึง**แก่ผู้ตรวจสอบอย่างไร?
- **A. (คำตอบที่ถูกต้อง – ไฮไลต์ในสไลด์)** สร้าง federated identity ให้ผู้ตรวจสอบแต่ละคนใน directory แล้วกำหนด role ที่มีสิทธิ์เหมาะสมให้ผู้ตรวจสอบแต่ละคนในทุกบัญชี
- B. เนื่องจากเป็นผู้ใช้ภายนอก ให้สร้าง IAM User ให้พวกเขาในทุกบัญชีพร้อมแนบ policies ที่เหมาะสม
- C. ให้ SSH keys สำหรับ EC2 instances ที่รันอยู่ใน Region สหรัฐฯ และเยอรมนีแก่พวกเขา เพื่อให้สำรวจสภาพแวดล้อมจากโฮสต์เหล่านั้นได้
- D. ในฐานะผู้ตรวจสอบ พวกเขาต้องมีสิทธิ์ root เพื่อดูทุกอย่างในบัญชี AWS จึงให้รหัสผ่าน root ของบัญชีแก่พวกเขา

# AWS กับโลกจริง
Amazon Web Services (AWS) มีบริการหลากหลายหมวดหมู่ เช่น:
- Compute (การประมวลผล)
- Storage (การจัดเก็บข้อมูล)
- Database (ฐานข้อมูล)
- Analytics (การวิเคราะห์ข้อมูล)
AWS มอบโซลูชันบนคลาวด์ให้ทั้งองค์กรขนาดใหญ่และธุรกิจขนาดเล็ก เพื่อขับเคลื่อนการดำเนินงานไปข้างหน้า:
- ได้เร็วขึ้น
- ด้วยต้นทุนที่ลดลง
- พร้อมความสามารถในการขยายขนาดตามความต้องการ
--- notes
Amazon Web Services (AWS) มีบริการหลากหลายหมวดหมู่ เช่น การประมวลผล การจัดเก็บข้อมูล ฐานข้อมูล และการวิเคราะห์ข้อมูล ซึ่งเปิดโอกาสให้ทั้งองค์กรขนาดใหญ่และธุรกิจขนาดเล็กใช้เทคโนโลยีขับเคลื่อนการดำเนินงานไปข้างหน้าได้เร็วขึ้น ด้วยต้นทุนที่ลดลง และสามารถขยายขนาดตามความต้องการได้

Emma (แม่ – mom) เป็นนักบัญชีเกษียณ และใช้ทักษะของเธอดูแลบัญชีของร้าน เธอรู้วิธีใช้เทคโนโลยีพื้นฐานและเก่งการใช้ Excel spreadsheet มาก
เธอไม่ขัดข้องที่จะช่วย Phillip ในครัว แต่เธอชอบใช้ทักษะการบัญชีเพื่อนำเงินกลับไปลงทุนในร้านมากกว่า เธออยากเพลิดเพลินกับชีวิตเกษียณมากขึ้น และไม่อยากเริ่มอาชีพที่สองเมื่อถึงวัยเกษียณ
แม้เธอจะสนุกกับการทำงานที่ร้าน แต่เธออยากใช้เวลากับงานธุรการให้น้อยลง เธออยากไปเข้าค่ายโยคะกับเพื่อนสนิทให้มากขึ้น และเมื่อมองไปข้างหน้า เธออยากมีเวลาอยู่กับหลาน ๆ ในอนาคต
