## งานที่ 2: ถ่าย Snapshots ของ Instance
ในส่วนนี้ คุณจะเรียนรู้วิธีใช้ AWS Command Line Interface (CLI) จัดการกระบวนการถ่าย snapshots ของ instance
บัญชี AWS ของคุณถูกจำกัดให้เก็บ snapshots ได้ 10,000 รายการในแต่ละ region นอกจากนี้ คุณถูกคิดค่าบริการทุกเดือนต่อกิกะไบต์ของข้อมูล snapshot ที่เก็บไว้ ค่าบริการนี้ถูกลดลงด้วยการที่ AWS ถ่าย snapshot แบบเพิ่มส่วน (incremental) หลังจาก snapshot แรก และด้วยการบีบอัดข้อมูล snapshot อย่างไรก็ตาม เพื่อให้การดูแลและต้นทุนเหมาะสมที่สุด เราแนะนำให้เฝ้าติดตามจำนวน snapshots ที่เก็บไว้ของแต่ละ instance และลบ snapshots เก่าที่ไม่ต้องการแล้วเป็นประจำ

### ถ่าย Snapshot แรก
ในขั้นตอนนี้ คุณจะถ่าย snapshot แรกของ instance **Processor**
ในการถ่าย snapshot คุณจะใช้คำสั่ง **aws ec2 create-snapshot** เนื่องจากคำสั่งนี้รับ volume ID คุณต้องหา volume ID ของ Amazon EBS volume ที่ต่อกับ Processor instance ก่อน โดยใช้คำสั่ง **aws ec2 describe-instances**
คำสั่ง **aws ec2 create-snapshot** จะถ่าย snapshot ของดิสก์ ณ เวลาที่สั่งคำสั่ง การเขียนลงดิสก์หลังจากนั้นจะไม่รวมอยู่ใน snapshot อย่างไรก็ตาม เนื่องจากการแคชการเขียนของแอปพลิเคชันและ OS snapshot ของ instance ที่กำลังทำงานอาจไม่สอดคล้องกัน (inconsistent) และทำให้ข้อมูลหายหรือเสียหาย ดังนั้นก่อนถ่าย snapshot ของ Processor instance คุณจะปิดเครื่องก่อน เพื่อให้ได้ snapshot ที่สอดคล้องกัน
หากคุณถ่าย snapshot ของ Amazon EBS volume รอง (ไม่ใช่ root) คุณสามารถยกเลิกการเมานต์ volume ก่อนถ่าย snapshot เพื่อให้ได้สำเนาที่สอดคล้องกันได้เช่นกัน สำหรับสำรองระบบฐานข้อมูล (เช่น MySQL) คุณสามารถ freeze ระบบไฟล์เพื่อระงับการเขียน หรือเปิดใช้การจำลองข้อมูล (replication) แล้วสำรอง read replica เป็นระยะ
- 36. เพื่อดูคำอธิบายแบบเต็มของ Processor instance ให้คัดลอกคำสั่งต่อไปนี้และรันจากภายใน instance ของคุณ:
```
aws ec2 describe-instances --filter 'Name=tag:Name,Values=Processor'
```
  - คำสั่งนี้ใช้ `--filter` เพื่อจำกัดผลลัพธ์ให้เหลือเฉพาะ instance ใหม่ที่สร้างในส่วนก่อนหน้า คำสั่งจะตอบกลับด้วยคำอธิบายแบบเต็มของ instance และคุณสมบัติทั้งหมดในรูปแบบ JSON ต่อไปคุณจะแก้คำสั่งนี้ให้ส่งกลับเฉพาะข้อมูลส่วนที่สนใจ คือข้อมูล Amazon EBS volume
- 37. เพื่อจำกัดผลลัพธ์ของคำสั่งก่อนหน้าให้แคบลงอีก ให้คัดลอกคำสั่งต่อไปนี้และรันจากภายใน instance ของคุณ:
```
aws ec2 describe-instances --filter 'Name=tag:Name,Values=Processor' --query 'Reservations[0].Instances[0].BlockDeviceMappings[0].Ebs.{VolumeId:VolumeId}'
```
  - คำสั่งที่แก้ไขนี้ใช้ `--query` ระบุ JMESPath query ที่ส่งกลับเฉพาะ volume ID ของ volume เดียว (root volume) ที่ต่อกับ Processor instance คุณควรได้ผลตอบกลับคล้ายกับ:
```
{
"VolumeId": "vol-1234abcd"
}
```
> หมายเหตุผู้แปล: ข้อความที่ดึงจาก PDF แสดงเป็น `-query` และ `{Volum eId` เพราะการตัดบรรทัด ได้เขียนให้ถูกต้องเป็น `--query` และ `{VolumeId:VolumeId}`
