### ตั้งตารางเวลาสร้าง Snapshots ครั้งถัดไป
ด้วยระบบตั้งเวลาของ Linux (cron) คุณตั้งกระบวนการ snapshot ที่เกิดซ้ำได้ง่าย เพื่อให้ snapshots ใหม่ของข้อมูลถูกถ่ายโดยอัตโนมัติ
สำหรับแล็บนี้ คุณจะตั้งให้สร้าง snapshot ทุกนาที เพื่อให้ตรวจผลงานได้ ในขั้นตอนถัดไป คุณจะใช้ระบบอัตโนมัติจัดการจำนวน snapshots ที่เก็บไว้ของ volume
> **หมายเหตุ:** ส่วนนี้ของแล็บไม่หยุด instance เพื่อให้สร้าง snapshots จำนวนมากสำหรับขั้นตอนถัดไปได้ หากต้องการรับประกันความสอดคล้อง คุณสามารถพัฒนาสคริปต์อัตโนมัติที่สมบูรณ์ขึ้น ซึ่งปิด instance หรือหยุดการเขียนดิสก์ (quiesce) ก่อน ตามที่กล่าวไว้ในงานที่ 2
- 45. เพื่อสร้างรายการ cron ที่ตั้งงานให้รันทุกนาที ให้คัดลอกคำสั่งต่อไปนี้ แทน **VOLUME-ID** ด้วย volume-id ของคุณ แล้วรันจากภายใน instance:
```
echo "* * * * * aws ec2 create-snapshot --volume-id VOLUME-ID >> /tmp/cronlog 2>&1" > cronjob
```
- 46. เพื่อตั้งเวลางาน cron นี้ ให้คัดลอกคำสั่งต่อไปนี้และรันจากภายใน instance:
```
crontab cronjob
```
  - **หมายเหตุ:** ใช้เวลา 1-2 นาที
- 47. เพื่อตรวจสอบว่า snapshots ถัดไปกำลังถูกสร้าง ให้คัดลอกคำสั่งต่อไปนี้ แทน **<volume-id>** ด้วย volume-id ของคุณ แล้วรันจากภายใน instance:

## งานที่ 3: โจทย์ท้าทาย: ซิงโครไนซ์ไฟล์กับ Amazon S3
ในส่วนนี้ คุณจะถูกท้าทายให้ซิงโครไนซ์เนื้อหาของไดเรกทอรีกับ Amazon S3 bucket ของคุณ
> **หมายเหตุ:** หากคุณคุ้นเคยกับ AWS อยู่แล้ว เราแนะนำให้ลองทำโจทย์นี้ด้วยตัวเองโดยใช้ข้อมูลในส่วนนี้ ก่อนอ่านเฉลยละเอียดในส่วนถัดไป เมื่อทำเสร็จแล้วให้ตรวจงานด้วยการทบทวนเฉลยละเอียด
### คำอธิบายโจทย์ (Challenge Description)
รันคำสั่งนี้บน EC2 instance เพื่อดาวน์โหลดชุดไฟล์ตัวอย่าง:
```

```
> หมายเหตุผู้แปล: URL ถูกตัดท้ายในต้นฉบับ PDF แต่ URL เต็มปรากฏในขั้นที่ 56: `https://aws-tc-largeobjects.s3-us-west-2.amazonaws.com/CUR-TF-200-RESOPS/lab5vocareum/files.zip`
แตกไฟล์เหล่านี้ แล้วใช้ AWS CLI ให้มากที่สุดเท่าที่ทำได้ หาวิธีทำสิ่งต่อไปนี้:
- เปิดใช้ versioning ให้ Amazon S3 bucket ของคุณ
- ใช้คำสั่ง AWS CLI คำสั่งเดียวซิงโครไนซ์ (sync) เนื้อหาของโฟลเดอร์ที่แตกไฟล์แล้วกับ Amazon S3 bucket
- แก้คำสั่งให้ลบไฟล์ออกจาก Amazon S3 เมื่อไฟล์ที่สอดคล้องกันถูกลบในเครื่องบน instance
- กู้คืนไฟล์ที่ถูกลบจาก Amazon S3 โดยใช้ versioning
**คำใบ้ (Hints):** คุณใช้คำสั่ง **aws s3api** เปิด versioning บน Amazon S3 bucket ได้
