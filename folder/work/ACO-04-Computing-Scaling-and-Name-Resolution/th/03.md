# ประเด็นสำคัญ (Key Takeaway)
- Amazon Route 53 รองรับนโยบายการกำหนดเส้นทางหลายแบบ
- Amazon Route53 ช่วย:
  - จดทะเบียน / โอนย้ายชื่อโดเมน
  - แปลงชื่อโดเมนเป็น IP address
- Amazon Route53 รองรับนโยบายการกำหนดเส้นทางหลายแบบ
- Amazon Route53 สามารถส่งทราฟฟิกไปยังทรัพยากรใน AWS regions ต่าง ๆ รวมถึงทรัพยากร on premises
- การกำหนดเส้นทางตามความหน่วง (Latency-based routing – LBR) ช่วยให้ DNS ส่งคำขอของผู้ใช้ไปยัง AWS Region ที่ตอบสนองเร็วที่สุด

Amazon Web Services (AWS) มีบริการหลากหลายหมวดหมู่ เช่น:

- ด้วยต้นทุนที่ลดลง
