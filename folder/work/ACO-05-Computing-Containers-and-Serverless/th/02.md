แผนภาพ (AWS Cloud → Region):
- 1. salesAnalysisReportDailyTrigger (Amazon CloudWatch event – ทริกเกอร์ทุกวันเวลา 20:00 วันจันทร์–เสาร์) → เรียก salesAnalysisReport Lambda function (ใช้ salesAnalysisReportRole IAM role)
- 2. salesAnalysisReport เรียก salesAnalysisReportDataExtractor Lambda function (ใช้ PyMySQL library ใน Lambda layer และใช้ salesAnalysisReportDERole IAM role)
- 3. salesAnalysisReportDataExtractor ดึงข้อมูลจากฐานข้อมูล mom_pop_db (MariaDB – MySQL) บน mompopcafe EC2 LAMP instance (อยู่ใน VPC → Subnet → Security group; EC2 instance contents)
- 4. ส่งข้อมูลกลับไปยัง salesAnalysisReport
- 5. salesAnalysisReport ส่งรายงานไปยัง salesAnalysisReportTopic (Amazon Simple Notification Service topic)
- 6. SNS ส่งอีเมลไปยังที่อยู่อีเมลของพ่อ (Pop's email address)
