=== P025
# Key pairs
การเข้าถึงระยะไกล (Remote Access):
**Linux – SSH**
- ใช้ SSH เพื่อล็อกอินเข้า instance
- การยืนยันตัวตนด้วยรหัสผ่านอย่างเดียวถูกปิดไว้โดยค่าเริ่มต้นบน Linux
- พอร์ต 22 (Port 22)
**Windows – RDP**
- ใช้ RDP เพื่อล็อกอินเข้า instances
- ใช้รหัสผ่านสุ่มที่เข้ารหัสไว้ ซึ่งถอดรหัสได้ด้วย private secret access key เท่านั้น
- พอร์ต 3389 (Port 3389)

=== P026
# การตั้งค่าความปลอดภัยของ instance ด้วยตนเอง
เปลี่ยนผู้ใช้และสิทธิ์หลังจากสร้าง instances แล้ว
- Windows:
  - ผสานรวมกับ AWS Directory Service
- Linux:
  - ใช้ single sign-on (SSO) แบบ Kerberos
  - สร้างคู่กุญแจ public/private ให้ผู้ใช้ด้วย `ssh-keygen`
  - เพิ่ม public key ของผู้ใช้ลงใน `~/.ssh/authorized_keys` ของผู้ใช้นั้น
วางกลยุทธ์การจัดการผู้ใช้ทั้งกลุ่มเครื่อง (fleet-wide user management):
- สร้าง AMIs
- ใช้ซอฟต์แวร์จัดการการตั้งค่า (configuration software)

=== P033
# สถานะในวงจรชีวิตของ EC2 instance (Lifecycle states)
แผนภาพสถานะ: Pending → Running; Running ↔ Rebooting; Running → (Stopping) → Stopped; Stopped → Running; Running → Shutting down → Terminated; Stopped → Terminating → Terminated
| สถานะ (State) | Running | Stopped | Terminated |
| คิดค่าบริการ? (Charged?) | คิดค่าบริการ (Charged) | ไม่คิด (Not charged) | ไม่คิด (Not charged) |
| Instance Store | คงอยู่ (Retained) | สูญหาย (Lost) | สูญหาย (Lost) |
| EBS Volumes | คงอยู่ (Retained) | คงอยู่ (Retained) | ถูกลบถ้าตั้งค่า DeleteOnTermination ไว้ |
| Public IP Address | คงอยู่ (Retained) | ถูกปล่อยคืน (Released) | ถูกปล่อยคืน (Released) |
| Elastic IP Address | คงอยู่ (Retained) | คงอยู่ (Retained) | ถูกยกเลิกการผูก (Disassociated) |

=== P034
# การไฮเบอร์เนต (Hibernation) ของ EC2 instance
แผนภาพ: Running → Stop-Hibernate → [Hibernation: Stopping → Stopped-Hibernate] → Start → Running
| | Running | Stop-Hibernate |
| คิดค่าบริการ? (Charged?) | คิดค่าบริการ (Charged) | ไม่คิด (Not charged)* |
| Instance Store | ไม่สามารถ stop หรือ hibernate instance ที่ใช้ instance store เป็นหลัก (instance store-backed) ได้ | |
| EBS Volumes | คงอยู่ (Retained) | คงอยู่ (Retained) |
| Public IP Address | คงอยู่ (Retained) | ถูกปล่อยคืน (Released) |
| Elastic IP Address | คงอยู่ (Retained) | คงอยู่ (Retained) |
| Private IP | คงอยู่ (Retained) | คงอยู่ (Retained) |
*คิดค่าบริการระหว่างอยู่ในสถานะ stopping

=== P035
# Hibernation: ข้อกำหนดเบื้องต้น
ในการเปิดใช้ hibernation ตอน launch คุณต้องมี:
- instance type และ AMI ที่รองรับ
- root EBS volume ที่เข้ารหัส
- เป็น On-Demand, Spot หรือ Reserved Instances
**หมายเหตุ (NOTE):** ไม่สามารถเปิดใช้ hibernation กับ Amazon EC2 instance ที่มีอยู่แล้วหลังจาก launch ได้

=== P036
# launch instance ใหม่
เหตุผลทั่วไปที่อาจต้อง launch instances ใหม่:
- Auto Scaling
- ประหยัดค่าใช้จ่าย (Cost savings)

=== P038
# การเลิกใช้ AMI (AMI deprecation)
การเลิกใช้ AMI ไม่ส่งผลต่อ instances ที่กำลังทำงานอยู่:
- Windows AMIs
  - ถูกเลิกใช้ไม่นานหลังออกอิมเมจใหม่
  - AMIs ออกภายใน 5 วันหลังแพตช์ของ Microsoft
  - ค้นหาด้วยชื่อ ไม่ใช่ AMI ID
- Amazon Linux AMIs
  - ใช้ได้นานหลายปี
query หา Amazon Linux AMI ล่าสุด:
```
aws ssm get-parameters-by-path --path "/aws/service/ami-amazon-linux-latest"
--query "Parameters[?Name=='/aws/service/ami-amazon-linux-latest/amzn-ami-hvm-x86_64-gp2'].Value" --output text
```

=== P042
# โมเดลความรับผิดชอบร่วมของ AWS (The AWS shared responsibility model)
**ลูกค้า (Customers) รับผิดชอบ:**
- แอปพลิเคชันและเนื้อหาของลูกค้า (Customer applications and content)
- แพลตฟอร์ม แอปพลิเคชัน การจัดการตัวตนและการเข้าถึง (Platform, applications, identity and access management)
- ระบบปฏิบัติการของ Amazon EC2 การตั้งค่าเครือข่ายและไฟร์วอลล์
- การเข้ารหัสข้อมูลฝั่งไคลเอนต์ (Client-side data encryption), การเข้ารหัสข้อมูลฝั่งเซิร์ฟเวอร์ (Server-side data encryption), การป้องกันทราฟฟิกเครือข่าย (Network traffic protection)
**AWS รับผิดชอบ:**
- AWS Foundation Services: Compute, Storage, Database, Networking
- AWS global infrastructure: Regions, Availability Zones, Edge locations

=== P044
# ตัวเลือกการซื้อ Amazon EC2 (1 จาก 2)
| ประเภท Instance | ประโยชน์ (Benefit) | กรณีการใช้งาน (Use Case) |
| On-Demand | ต้นทุนต่ำและยืดหยุ่น | งานระยะสั้น งานที่พุ่งขึ้นเป็นช่วง ๆ หรือคาดเดาไม่ได้; แอปพลิเคชันที่กำลังพัฒนาหรือทดสอบ |
| Reserved | No Upfront RI ไม่ต้องจ่ายเงินล่วงหน้า; ส่วนลดสูงสุด 75% เมื่อเทียบกับราคา On-Demand และมีการจองความจุ (capacity reservations) | การใช้งานคงที่หรือคาดเดาได้; ต้องการความจุที่จองไว้ |
| Spot | เวลาเริ่มและสิ้นสุดยืดหยุ่น; คุ้มค่าเมื่อราคาประมวลผลต่ำมาก | ความต้องการประมวลผลเร่งด่วนพร้อมส่วนลดสูง; ต้องการความจุเพิ่มเติมจำนวนมาก |

| Dedicated Instances | instances รันบนฮาร์ดแวร์ที่อุทิศให้บัญชีเดียว | เมื่อมีข้อจำกัดด้านกฎระเบียบที่กำหนดให้ต้องแยกทางกายภาพ |

=== P046
# กลไกของ Spot Instance
- ระบุพฤติกรรมเมื่อถูกขัดจังหวะ (interruption behavior):
  - Hibernate: บันทึกสถานะหน่วยความจำลงดิสก์ (สูงสุด 122GB)
  - Stop
  - Terminate
- คำเตือนก่อนขัดจังหวะ: instance จะได้รับแจ้งล่วงหน้า 2 นาที
- ผูกกับเหตุการณ์ปิดระบบปฏิบัติการเพื่อเก็บกวาด (clean up):
  - Linux: ผูกกับ runlevels (`/etc/rc0.d`, `/etc/rc6.d`)
  - Windows: เพิ่มสคริปต์ให้เหตุการณ์ Shutdown ใน local computer policy
> **แนวปฏิบัติที่ดีที่สุด (Best Practice):** ใช้ root Amazon EBS volumes ที่เข้ารหัสเพื่อรักษาความปลอดภัยของข้อมูลสถานะ
