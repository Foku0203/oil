```
more UserData.txt
```
สคริปต์นี้ทำงานเริ่มต้นหลายอย่าง รวมถึงอัปเดตซอฟต์แวร์ที่ติดตั้งทั้งหมดในเครื่อง และติดตั้งเว็บแอปพลิเคชัน PHP ขนาดเล็กที่ใช้จำลองโหลด CPU สูงบน instance ได้ ใกล้ท้ายสคริปต์ คุณจะเห็นบรรทัดต่อไปนี้:
```
find -wholename /root/.*history -wholename /home/*/.*histo
find / -name 'authorized_keys' -exec rm -f {} \;
rm -rf /var/lib/cloud/data/scripts/*
```
> หมายเหตุผู้แปล: บรรทัดแรกถูกตัดท้ายในต้นฉบับ PDF คำสั่งเต็มที่น่าจะเป็น (เติมจากแล็บ AWS ฉบับเดียวกัน โปรดตรวจกับหน้าแล็บจริง): `find -wholename /root/.*history -wholename /home/*/.*history -exec rm -f {} \;`
บรรทัดเหล่านี้ลบประวัติคำสั่งหรือข้อมูลด้านความปลอดภัยใด ๆ ที่อาจหลงเหลืออยู่บน instance โดยไม่ตั้งใจตอนสร้างอิมเมจ

  - ที่ **VPC** เลือก **Lab VPC**
  - ตอนนี้คุณจะระบุ subnets ที่ load balancer จะใช้ load balancer จะหันหน้าสู่อินเทอร์เน็ต (internet facing) จึงต้องเลือก public subnets ทั้งสอง
  - เลือก Availability Zone แรกที่แสดง จากเมนู **Subnet** ที่แสดง เลือก **Public Subnet 1**
  - เลือก Availability Zone ที่สองที่แสดง จากเมนู **Subnet** ที่แสดง เลือก **Public Subnet 2**
